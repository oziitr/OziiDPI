# Güvenlik

OziiDPI yalnız yerel makinede çalışan bir ağ aracı olarak tasarlanmıştır. Yerel
proxy dış ağ arayüzlerine açılmamalı ve `127.0.0.1` sınırı korunmalıdır.

Bir güvenlik sorunu bulursanız ayrıntıları herkese açık issue içine koymayın.
GitHub deposundaki **Security > Report a vulnerability** özelliği etkinse bu
kanalı kullanın.

Desteklenen sürüm: 1.1.x

Yapımcı: ozii
