# OziiDPI Chrome entegrasyonu

Bu uzantı normal Chrome profilinin proxy ayarını OziiDPI uygulamasındaki anahtara
göre açıp kapatır. Chrome kapanmaz ve ayrı profil oluşturulmaz.

Bir kez kurmak için:

1. OziiDPI içindeki `NORMAL CHROME'U BAĞLA` düğmesine basın.
2. Açılan `chrome://extensions` sayfasında Geliştirici modu seçeneğini açın.
3. `Paketlenmemiş öğe yükle` seçeneğine basıp bu klasörü seçin.

Uzantı devre dışı kalırsa veya OziiDPI kapanırsa Chrome proxy ayarı temizlenir.

Yapımcı: ozii
